# Spendle

GitHub Pagesだけで動く、シンプルな支出管理Webアプリです。割り勘のシーンを想定し、「自分が実際に支払うべき金額（実質負担額）」をひと目で把握できることを重視しています。

## 特徴

- 📱 モバイルファーストなUIで、スマホからでも入力しやすい
- 🧮 割り勘後の実質負担額を自動計算
- 🏷️ カテゴリごとの予算管理
- 💾 データはブラウザ内（LocalStorage）に保存、サーバー送信なし
- 📤 CSVエクスポートに対応
- 📲 ホーム画面に追加してPWA風に利用可能
- ⚙️ ビルド不要、Vanilla JavaScriptのみで実装

## 使い方

ビルドやnpmのインストールは不要です。`index.html` をブラウザで開くか、任意の静的ファイルサーバーで公開するだけで動作します。

## ファイル構成

```text
index.html        画面の骨組み
css/style.css     モバイルファーストの見た目
js/app.js         画面描画とイベント処理
js/storage.js     LocalStorageの読み書き
js/categories.js  カテゴリと実質負担額の計算
js/expenses.js    支出の作成・検証・並び替え
js/csv.js         CSVエクスポート
```

カテゴリのアイコンには、CDNから読み込むBootstrap Iconsを使用しています。Bootstrap本体のJavaScriptも読み込んでいますが、画面の状態管理やアプリのロジックはすべてVanilla JavaScriptで実装しています。

## データの保存方式

すべてのデータはブラウザのLocalStorageキー `simple-expense-manager-data` に保存されます。保存値は `version: 1` を持つJSON形式で、カテゴリ（名称・アイコン・予算）と支出の情報をまとめて保持します。外部サーバーへの送信は一切行いません。

そのため、ブラウザのサイトデータ削除や端末・ブラウザの変更によってデータが失われる可能性があります。大切な記録は、設定画面のCSVエクスポート機能を使って定期的にバックアップすることをおすすめします。CSVはUTF-8 BOM付きで出力されるため、Excelなどでも文字化けせずに開けます。

## PWAとしての利用

GitHub PagesなどHTTPSで公開されたURLをスマートフォンで開き、ブラウザの「ホーム画面に追加」を選択すると、アプリのように起動できます。ホーム画面用アイコンには淡いブルーの背景を設定しているため、透明なSVGが黒背景で表示されてしまう問題を回避しています。
